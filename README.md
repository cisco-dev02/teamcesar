# Team Cesar Muay Thai Kids — Next.js

Landing page responsiva em Next.js App Router, com identidade visual própria para o projeto Muay Thai Kids da Team Cesar.

## Identidade visual

- **Marca principal:** Team Cesar Muay Thai Kids.
- **Vermelho:** `#D71920` — CTA, energia e destaques.
- **Azul:** `#164A8A` — confiança, equilíbrio e blocos institucionais.
- **Preto:** `#111318` — tipografia e contraste.
- **Branco:** `#FFFFFF` — base e respiro.
- **Cinza claro:** `#F5F7FA` — alternância de seções.
- **Dourado:** `#D9AD39` — pequenos detalhes.

### Direção
Clean, clara, editorial e esportiva. Tipografia Manrope nos títulos e DM Sans no corpo. Bastante espaço em branco, cards com bordas discretas, vermelho para ação e azul como cor de apoio.

Viana Jiu-Jitsu e Fifty Fifty Fight aparecem exclusivamente como unidades parceiras/localizações. A Team Cesar é a marca responsável pelas aulas.

## Rodar localmente

Requisitos: Node.js 18.17+.

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

Para produção:

```bash
npm run build
npm start
```

## Antes de publicar — confirmar

1. **Horário da Viana:** o briefing inicial informa Muay Thai Kids às terças, quintas e sábados às 18h. A arte de horários enviada depois mostra Muay Thai às segundas, quartas e sextas às 7h, 18h e 19h, e Jiu-Jitsu Kids às terças e quintas às 19h. A página está usando o horário do briefing inicial para a turma Kids. Confirme esse horário antes de publicar.
2. Confirmar a frequência semanal incluída no Personal Fight Infantil de R$ 120/mês.
3. Confirmar qual academia serve de referência para o limite de 5 km.
4. Confirmar os protocolos específicos de segurança, supervisão e primeiros socorros.
5. Substituir o espaço de depoimento por relato real autorizado.
6. Usar fotos reais das crianças somente com autorização dos responsáveis.
7. Revisar os endereços e a localização no mapa.
